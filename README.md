## ✨ Fitur

| Fitur | Keterangan |
|-------|------------|
| 🧾 **Live Preview** | Perubahan form langsung terlihat di preview invoice |
| 📅 **Auto Invoice Number** | Nomor invoice otomatis mengikuti tanggal yang dipilih |
| 🏷️ **Preset Project** | Pilih jenis project (Website / Undangan / Custom) |
| ➕ **Multi Item** | Tambah & hapus item invoice tanpa batas |
| 💰 **Kalkulasi Otomatis** | Subtotal, diskon, adjustment, grand total dihitung realtime |
| 💾 **Simpan Draft** | Data tersimpan di localStorage browser |
| 🖼️ **Export PNG** | Download invoice sebagai gambar PNG resolusi tinggi |
| 🖨️ **Print Ready** | Layout cetak A4 optimized via `@media print` |
| 📱 **Responsive** | Tampilan menyesuaikan layar desktop & tablet |

## 🚀 Quick Start

```bash
# Clone repo
git clone https://github.com/pulba/innvoice.git

# Buka langsung di browser
# Tidak perlu install apapun — zero dependency!
```

Atau cukup buka file `pulba-digital-invoice-generator.html` di browser favorit kamu.

## 📁 Struktur File

```
innvoice/
├── pulba-digital-invoice-generator.html   # Halaman utama
├── style.css                              # Stylesheet terpisah
├── script.js                              # Logika invoice & export
├── logo.webp                              # Logo Pulba Digital
├── favicon.png                            # Favicon browser tab
└── README.md                              # Dokumentasi
```

---

## 🛠️ Tech Stack

- **HTML5** — Struktur semantik
- **CSS3** — Variabel, grid layout, media queries
- **JavaScript (Vanilla)** — Kalkulasi, render, export
- **Google Fonts** — Roboto
- **html2canvas** — Export invoice ke PNG (CDN)
- **jsPDF** — PDF support (CDN)

## 📸 Preview
